# RTS Autocare — website files

This folder contains the complete source for the RTS Autocare landing page.

## Run it locally
1. Install Node.js 20 or newer.
2. In this folder run: `npm install`
3. Then run: `npm run dev` and open the address it prints.

## Publish it
Run `npm run build`. Give the resulting output folder to any web host,
or hand this whole folder to a developer / host that supports TanStack Start.

## What's inside
- `src/routes/index.tsx` — the landing page
- `src/components/site/` — page sections, contact form, and your business details
- `src/components/site/data.ts` — phone numbers, address, hours, services, reviews
- `src/assets/` — your photos and logo
- `src/styles.css` — colours, fonts and the overall look
